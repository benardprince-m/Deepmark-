## [v1.0.0-beta] - 2026-08-05

### Added
- Initial Founder Beta release
- JWT authentication system
- Workspace management with isolation
- User registration and login
- Startup profile management
- Campaign creation and tracking
- AI-powered content generation via OpenRouter
- Provider routing system (Claude, GPT-4, Gemini support)
- Memory Engine for persistent context
- Thinking Panel for AI reasoning
- Health check endpoints
- API v1 routes structure
- Supabase database integration
- Row Level Security (RLS) policies

### Security
- JWT-based authentication
- Protected API routes
- Workspace-scoped data access
- Service role key security

### Infrastructure
- Railway deployment ready
- Supabase PostgreSQL database
- Environment variable configuration
- Production build configuration
